.. _f2py-win-intel:

==============================
F2PY and Windows Intel Fortran
==============================

The supported Intel compiler is the LLVM based ``ifx`` from the free Intel
oneAPI toolkit. The classic ``ifort`` compiler was discontinued with the oneAPI
2025 release; the examples below use ``ifx``.

.. note::

	This document does not endorse the usage of Intel in downstream
	projects due to the issues pertaining to `disassembly of components and
	liability`_.

	Neither the Intel Distribution for Python nor the Intel C/C++ compilers
	are required; MSVC serves as the C compiler.

- The `Intel Fortran Compilers`_ install through the Intel oneAPI toolkit or as
  a standalone component. The 2026.2 release no longer supports Windows 10 or
  Windows Server 2019.

We will consider the classic example of the generation of Fibonacci numbers,
``fib1.f``, given by:

.. literalinclude:: ../code/fib1.f
   :language: fortran

For ``cmd.exe`` fans, using the Intel oneAPI command prompt is the easiest
approach: ``setvars.bat`` loads the environment for both ``ifx`` and MSVC.
Helper batch scripts are also provided.

.. code-block:: bat

   rem cmd.exe
   "C:\Program Files (x86)\Intel\oneAPI\setvars.bat"
   set FC=ifx
   python -m numpy.f2py -c fib1.f -m fib1 --f90flags="/names:lowercase /assume:underscore"

PowerShell needs an extra step: load the oneAPI environment (so ``ifx`` and the
MSVC linker are on ``PATH``) into a new shell, then invoke ``f2py`` as usual:

.. code-block:: powershell

   # Load the oneAPI environment and start a PowerShell that inherits it
   cmd.exe /k '"C:\Program Files (x86)\Intel\oneAPI\setvars.bat" && pwsh'
   $env:FC = 'ifx'
   python -m numpy.f2py -c fib1.f -m fib1 --f90flags='/names:lowercase /assume:underscore'

The paths above are those of a default installation with the component
directory layout. With the unified directory layout, call
``C:\Program Files (x86)\Intel\oneAPI\<toolkit-version>\oneapi-vars.bat``
instead.

Symbol names
============

On Windows, ``ifx`` converts external names to uppercase and appends no
trailing underscore. The C wrapper generated by ``f2py`` calls the lowercase
names with a trailing underscore that ``gfortran`` and ``ifx`` on Linux
produce, so without the options above the link step fails with:

.. code-block:: text

   fib1module.c.obj : error LNK2001: unresolved external symbol fib_

``/names:lowercase /assume:underscore`` select the matching names. ``f2py``
passes ``--f90flags`` (and ``--f77flags``) to every Fortran source, fixed form
included. ``numpy.distutils`` used to add the same two options for the Intel
compilers on Windows.

Importing ifx-built modules
===========================

``meson`` compiles with the multithreaded DLL runtime (``/MD``), so a module
built with ``ifx`` depends on Intel runtime libraries such as
``libifcoremd.dll`` and ``libmmd.dll``. ``setvars.bat`` adds their directory to
``PATH``, which Python does not search when it imports an extension module (see
:ref:`f2py-win-dlls`). Register the directory before the import:

.. code-block:: python

   import os
   os.add_dll_directory(r"C:\Program Files (x86)\Intel\oneAPI\compiler\latest\bin")
   import fib1

Machines without the compiler can get the same libraries from the `Intel
Fortran Compiler Runtime`_ installer.
