``f2py`` can leave an ``OPTIONAL`` dummy absent
-----------------------------------------------
An ``OPTIONAL`` dummy that the Python caller omits, or passes as ``None``,
is left absent, so ``present()`` is false. The ``absent`` attribute selects
this call. A signature-file ``optional`` attribute keeps the previous
default value unless the file also names ``absent``. An unsupported kind
from Fortran source drops ``absent`` and keeps the previous call, after a
build message. A signature file that writes ``absent`` on such a kind is
an error. An explicit init expression also drops ``absent`` and keeps that
default.
