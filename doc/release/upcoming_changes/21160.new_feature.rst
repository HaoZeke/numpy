``f2py`` derived type support
-----------------------------
``f2py`` can now wrap Fortran derived types, generating Python classes with
attribute access, constructors, and repr. Two strategies are supported:

* **bind(c) types**: mapped to C structs with direct field access and zero-copy
  NumPy array views for array members.
* **Opaque types**: arbitrary Fortran types (no ``bind(c)`` required) wrapped via
  auto-generated Fortran ``bind(c)`` accessor routines.

Supported features include:

* Fixed-size, allocatable, and pointer array members (1D and multi-dimensional)
* Nested types and arrays of derived types as routine arguments
* Inheritance (``extends``) with abstract base types and ``isinstance()`` support
* Type-bound procedures, generic bindings with runtime dispatch, and finalizers
* Operator overloading (arithmetic, comparison, assignment)
* Character string members (fixed-length and deferred-length allocatable)
* Complex-valued members (compatible with ``npy_cfloat``/``npy_cdouble``)
* Default initialization and ``SEQUENCE`` types
* KIND-parameterized types with multi-kind specialization
* LEN-parameterized types
* Functions returning derived types and assumed-shape array arguments
* Array API compatible input for array member setters (accepts ``__dlpack__``)
