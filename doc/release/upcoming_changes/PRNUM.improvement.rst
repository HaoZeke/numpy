Rewritten "Using Python as glue" user guide page
------------------------------------------------
The :doc:`/user/c-info.python-as-glue` page of the user guide was rewritten in
the style of the rest of the documentation. Its F2PY, Cython, and ctypes
examples now build and run as shown, and the page describes current tools such
as pybind11, nanobind, CFFI, and PyO3 instead of g77, Pyfort, and
``distutils``.
