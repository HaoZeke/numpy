``f2py`` infers a call-back signature from the call that uses it
-----------------------------------------------------------------
A routine that does not call an ``external`` argument, but passes it on,
now gives that argument the signature of the call. A callback invoked as
``cb(1)`` takes one integer, and each routine keeps its own callback.
A callback with no call anywhere still has no arguments: it is a function
of its declared type, or a subroutine if it has no type. An interface
block, or a signature file that already describes the callback, is left
as written.
