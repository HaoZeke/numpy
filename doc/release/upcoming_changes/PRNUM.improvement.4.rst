``f2py`` generated code relies less on C API outside the Limited API
--------------------------------------------------------------------
The C code generated by ``f2py``, and its ``fortranobject.c`` runtime, no longer use ``PyTupleObject``, ``Py_complex``, ``Py_SETREF``, ``PyObject_Print`` or the CPython-only ``PyBytes``, ``PyUnicode`` and ``PySequence_Fast`` access macros, and include the C standard headers they use.
This is a step towards building ``f2py`` extension modules against the Python Limited API.
Diagnostics that print a Python object, such as ``<module>.error is related to ...``, are now written to ``sys.stderr``.
